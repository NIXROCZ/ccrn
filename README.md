# Raising Noble

A digital storefront for children's education kits. Astro on Cloudflare Workers,
with Stripe for payments, Resend for email, D1 for orders and R2 for the files.

**Setting this up for the first time? → [`docs/GO-LIVE.md`](docs/GO-LIVE.md).**
That is the one document you need; it assumes no prior experience and goes from
empty accounts to taking money.

## How a purchase flows

```
Stripe Checkout  →  webhook  →  D1 records the order and what it entitles
                                        ↓
                       Resend emails a permanent library link
                                        ↓
              downloads stream from a private R2 bucket through the Worker
```

The kit files are never public. R2 has no public URL; the Worker reads the
object, checks the buyer's entitlement in D1, appends a `LICENCE.txt` stamped
with their email and order number, and streams the result.

```bash
npm ci            # install
```

## Two things that will bite you

**`SITE_PEPPER` can never change.** It hashes every gift-card code. Change it and
every card in circulation stops working. Generate once, store in a password
manager.

**Preview and production currently share one D1 database**, so test orders land
in the real orders table. Split them before taking real money — see
`docs/HANDOVER.md`.

**The store sells worldwide but collects no tax anywhere.** Selling digital
products to EU or UK consumers requires VAT registration from the first sale,
with no threshold. Turn on Stripe Tax before advertising outside Australia —
see `docs/GOING-INTERNATIONAL.md`.
